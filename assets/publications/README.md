# Publication images

Place one PNG image for each publication in this folder. The website already references these exact filenames:

- `know-your-role.png`
- `biased-evaluators-rag.png`
- `legal-search-style-translation.png`
- `mixed-initiative-survey.png`
- `multilingual-medical-asr.png`

Recommended export: 1200 × 800 px (3:2), PNG or WebP-quality artwork saved as PNG. Use a representative model diagram, teaser figure, or result visualization with readable large labels. The cards crop images to a 3:2 thumbnail on desktop, so keep important content away from the outer edges.

Until an image is added, the website displays a placeholder containing its expected filename.
